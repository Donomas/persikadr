# Persikadr

Видеоконвертер для Windows. Обрабатывает файлы локально, поддерживает пакетную конвертацию и аппаратное ускорение FFmpeg при наличии совместимой видеокарты.

**Форматы результата:** MP4, MKV, MOV, AVI, WebM, MP3 и MPEG-2 для DVD PAL/NTSC. Можно выбрать кодек, качество, разрешение и имена файлов.

## Использование

Добавьте файлы, выберите настройки и нажмите «Конвертировать». По умолчанию результаты сохраняются в системную папку «Видео» пользователя, обычно `C:\Users\<имя>\Videos`. Другую папку можно выбрать в интерфейсе.

## Локальная сборка EXE

Распакуйте исходники в отдельную папку. Установите Python 3.11 x64 для Windows и выполните в PowerShell из папки проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_exe.py
```

Готовый файл находится в `dist/Persikadr.exe`. Для запуска из исходников используйте `.\.venv\Scripts\python.exe app.py`.
